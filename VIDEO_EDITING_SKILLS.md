## Notes
- Duplicates skipped: `hyperframes`, `hyperframes-cli`, `hyperframes-registry` from herk-edit-kit (the official HeyGen versions are installed instead).
- Some skills need extra tools or keys: FFmpeg (installed), Whisper for captions, Node for Remotion/HyperFrames, and API keys for HeyGen / ElevenLabs / Google (YouTube Data API) where a skill calls those services.
- All bundled scripts were scanned for risky patterns (piping downloads to a shell, credential access, etc.) before install; none were found.
