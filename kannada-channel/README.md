# Kannada Funny Channel – Audio Bundle (mobile workflow)

Everything here can be done from a phone.

## Files
| File | What it is |
|---|---|
| `COPYRIGHT_RULES.md` | What audio is safe to use where |
| `07_Movie_Dialogue_Mimicry/1990s_batch1.md` | First 20 famous 1990s comedy films/scenes to cover – fill in or confirm the dialogue |
| `09_Original_Catchphrases/catchphrases.md` | 50 original Kannada meme lines (100% yours, no copyright risk) |
| `RECORDING_GUIDE.md` | How to record good meme audio on a phone |

## Mobile workflow
1. **Read and correct** the lists here (GitHub app or this Claude chat).
2. **Record** lines with your phone's voice recorder app. Name them `MOV001`, `CP001`, etc.
3. **Send recordings** back into this chat (attach) – Claude trims, levels volume and sorts them by emotion.
4. **Edit videos** in CapCut / VN on the phone using the cleaned files.
5. **Original movie sounds**: use them only inside YouTube Shorts / Instagram Reels via the in-app *Add sound* library.
